# SOIA 教育课程技能库

面向课程大纲设计、教案编写与讲义结构化的可复用 AI 技能集合。

## 技能目录

| 技能名 | 一句话简介 |
|---|---|
| `soia-edu-compose-lesson-plan` | 按课程大纲编写包含时间安排、课堂互动和作业的可执行教案与讲义结构。 |
| `soia-edu-design-course-outline` | 根据主题、受众和课时约束设计目标可测的课程大纲。 |

## 安装

将 `<技能>` 替换为上表中的技能名：

```bash
npx skills add soia-team/soia-open-edu-course-skills -g -a '*' -s <技能> -y
```

例如安装课程大纲设计技能：

```bash
npx skills add soia-team/soia-open-edu-course-skills -g -a '*' -s soia-edu-design-course-outline -y
```
